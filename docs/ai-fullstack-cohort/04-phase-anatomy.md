# Course Phase Anatomy

*NIAT · AI FullStack Elite Cohort · Companion to the Execution Plan*

How each course's delivery phases, practice rhythm, weekly gates, and skill assessments combine to produce its learning outcome. Weeks are cohort-relative (each university anchors week 1 to its own start date). Sessions in brackets.

---

## The three phases, and why the arc maximises outcomes

### Micro-cycles — *Encode & retrieve*
Short learn→quiz→practice loops. Practice: 6–12 MCQs per concept node + short coding drills. Builds accurate foundations; spacing across both tracks protects novices.

### Studio — *Fluency & feedback*
45 min segmented teaching + 2 h 15 continuous lab. Practice: 2–4 build tasks per skill node. Long labs create fluency; same-day proximity keeps feedback tight.

### Project — *Transfer & integration*
Multi-session builds with rubrics. Practice: skill assessments (checkpoints) + review/debug items. This is the phase employers see — the arc exists to reach it.

**Legend:** ◆ = weekly mastery gate (day 6, the intervention trigger) · ⬦ = skill assessment (bi-weekly checkpoint, EXAM-weight) · segment shade = phase depth (light → solid): micro → studio → project · AM/PM = morning/afternoon track

## Course by course

### 🅰️ AM — Computer Programming using Python (28)
*Sem A wk 2–7 · standard arc, 45/45/10*

**Arc:** MICRO — syntax→loops (45%) → STUDIO — strings·lists·functions·dicts (45%) → MINI-PROJ (10%)

Gates across 7 weeks (weekly, alternating).

**Exit:** Writes correct Python unaided (gates are AI-free); fluent in Python's error patterns; first git-submitted mini-project.

### 🅿️ PM — Web App Development — HTML · CSS · Tailwind (15)
*Sem A wk 2–4 · compact standard arc*

**Arc:** MICRO — HTML·CSS fundamentals → STUDIO — flexbox·grid·Tailwind → RESPONSIVE PAGE BUILDS

Gates across 3 weeks.

**Exit:** Ships a responsive, Tailwind-styled page (skill-assessed twice) and can judge AI-generated layout — handing off to the JS course.

### 🅿️ PM — Frontend Development — JavaScript (16)
*Sem A wk 5–7 (soft seam from wk 4) · standard arc · pure reuse*

**Arc:** MICRO — JS foundations·DOM → STUDIO — events·HTTP·forms·builds → MODERN JS — classes→promises→modules

Gates across 3 weeks.

**Exit:** Reads and writes modern JS — DOM, events, fetch, promises, modules — ending exactly where React begins. All 16 sessions re-cut from two recorded courses (Build Your Own Dynamic Web Application + JS Essentials); the MRV React collapse traced to rushed JS, and this full-width course is the fix.

### 🅰️ AM — Frontend with React + TypeScript (28)
*Sem A wk 8–14 (around Mid-1 shield) · standard arc*

**Arc:** MICRO — components·props·state → STUDIO — hooks·effects·TS → PROJECT — routing→auth→context = one app

Gates across 6 weeks.

**Exit:** Typed, tested (Vitest/RTL), auth-guarded React app deployed — the phase-3 app *is* the final skill assessment. ⚠ Tightest window of the year (1.18) — Saturday labs are load-bearing.

### 🅿️ PM — Database Management Systems (28)
*Sem A wk 8–14 · standard arc + schema capstone*

**Arc:** MICRO — SQL drills·querying → STUDIO — modelling·joins·Mongo → SCHEMA CAPSTONE

Gates across 6 weeks.

**Exit:** Designs and builds the data layer for a given product spec (graded capstone) — which Backend starts consuming at wk 17.

### 🅰️ AM — Building LLM Applications (30)
*Sem B wk 1–7 (around Sankranthi) · build-first spiral*

**Arc:** BUILD — assistant→UI→deploy → CONCEPT — LLMs → STUDIO — tools·RAG·agents → BUILD — RAG agent·MCP → CONCEPT — evals·security → BUILD — evaluated app

Gates across 7 weeks.

**Exit:** Ships a provider-portable, retrieval-grounded, evaluated and guarded LLM app. The spiral (build → concept → build) is deliberate: building first creates the need the theory then answers.

### 🅿️ PM — Backend with FastAPI (14)
*Sem B wk 1–4 · compact standard arc*

**Arc:** MICRO — FastAPI·routing·models → STUDIO — SQL·auth·SSE → SHIP — deploy + frontend integration

Gates across 4 weeks.

**Exit:** Ships a deployed, JWT-secured, streaming-capable API integrated with the React frontend — just enough backend; Node depth waits for Year 2.

### 🅿️ PM — Application Development using Coding Agents (22)
*Sem B wk 5–10 · standard arc, hands-on throughout · 3 freed slots = maintenance windows*

**Arc:** MICRO — how agents work·config·prompting → STUDIO — codebases·features·review labs → PROJECT — cloud agents·deploy·portfolio

Gates across 7 weeks.

**Exit:** Directs, reviews and verifies agent work professionally; skill assessments here are review/debug format — "find the bug in this AI-generated code", "write the spec that produces X".

### 🧵 TH — Data Structures & Algorithms (C++) (51)
*Thread strand, Sem A wk 10 → Sem B · 1 problem-session/day + 6 Saturdays · full course, zero trim*

**Arc:** FOUNDATIONS — C++·STL·complexity (Module I, in-course) → PATTERN PROBLEM-SETS — arrays→strings→recursion→sorting→bits (Module II–V) → CONSOLIDATION · CONTESTS · DSA EXAM-PREP (wk 11–13 PM)

Gates across 5 weeks (of thread activity shown).

**Exit:** Full BOS Data Structures syllabus — all 51 recorded sessions, C++ bridge as Module I in-course (no sem-break bootcamp) — substantially complete before Sem-2 Mid-1; solves core patterns in C++ under contest time pressure. New-session density is **shaped**: ~3/wk while both build tracks carry new content, daily otherwise; a slipped React gate downshifts the thread to drill-only (parallel-load control). Advanced DSA (trees, graphs, DP) in Year 2.

### 🎓 CAP (AM) — AI FullStack Capstone (12 blocks + 6 comm)
*Sem B wk 9–13 mornings · all-project, paired with Agents → DSA afternoons*

**Arc:** SCOPE & SPEC → BUILD SPRINTS — agent-native, applying each afternoon's techniques → EVALS & HARDENING → DEMO PREP

Gates across 7 weeks.

**Exit:** A shipped product (React/TS + Node + LLM feature + evals), a graded agent-workflow transcript portfolio, and Demo Day in the Sem-B exam window.
