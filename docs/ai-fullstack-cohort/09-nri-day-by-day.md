# NRI Day-by-Day — the BOA Runbook

*Academic Planning · NRI Institute of Technology · Daily Execution Plan (DEP) · v1 — Sem 1 Weeks 1–3, for campus BOA review*

The lowest planning layer: which course runs in which slot on which day, in sync with the delivery mode. Reads from the [Prod Sequences](08-nri-production-sequence.md) page (slot numbers are that page's slot numbers, order never broken) and the 5+1 weekly plan. Slot = 1 hour · S1–S3 = AM block · S4–S6 = PM block · S7 = thread · Saturday = BOS day. **Week 1 is the onboarding week — Induction + Dev Tools only; course sequences start week 2.** Weeks 3+ generated the same way after this format is signed off.

**Stats:** Wk 1 = onboarding (IND 1–7 + DT 1–14) · Wk 2 = courses start (PY 1–11 · WAD 1–11, MC) · 7×6 slots × days per week · Wk 3 = MC→Studio (PY/WAD 12–23 · GAI 4–6)

## Reading the runbook

### Cell anatomy & lanes
- **PY·5 (P)** — Course code · prod-sequence slot number · slot type (L Lecture / P Practice). The small line = the slot's lead unit, verbatim from the sequence. IND = Induction · DT = Dev Tools · GAI = Intro GenAI.
- **EXT** — Practice extension / buffer — drawn from the APD buffer pool; first candidates for remediation (R4) and deviation catch-up, never pre-assigned new content.
- **OPS · ASSESS · BOS** — Onboarding/ops · Friday assessment block (MQ/SA) · Saturday BOS-day subjects.

### Flags used above
- **①** — Week-1 exit gate: environment working + **first commit pushed** + platform fluent — checked in the Friday first-commit workshop.
- **②** — Adjacent Lectures for one course inside a day — allowed only when one is a short kickoff/walkthrough session (R3 pairing); logged as a deviation otherwise (R1).
- **③** — MQ / NxtMock units embedded mid-sequence **do not run mid-week**: MQ executes in the Friday assessment block (R9/R13), NxtMock as the mock-defend inside SA windows (retarget policy). Sequence position = earliest eligibility — so wk-2 Friday runs Python M1 only; WAD M1 (slot 12) lands in the wk-3 block.
