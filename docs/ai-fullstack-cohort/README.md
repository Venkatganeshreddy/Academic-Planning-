# AI FullStack Elite Cohort — Program Design

Markdown transcription of the [Program Design artifact](https://claude.ai/code/artifact/ef947117-8457-46a6-93c7-cef8b67e776d), a 9-tab planning document covering NIAT's AI FullStack Developer Track curriculum, delivery model, and its co-delivery plan with NRI Institute of Technology.

## Tabs

1. [Curriculum](01-curriculum.md) — course outlines, modules, and design rationale (what's taught and why)
2. [Course Contents](02-course-contents.md) — every module and session, listed in full
3. [Execution Plan](03-execution-plan.md) — the four delivery models and the mapped 1-year timeline
4. [Phase Anatomy](04-phase-anatomy.md) — per-course delivery-phase breakdown (micro-cycles → studio → project)
5. [Student View](05-student-view.md) — prototype spec for the student-facing daily/weekly UI
6. [NRI Planning System](06-nri-planning-system.md) — Semester 1 baseline academic plan for NRI (slot economics, scheduling rules, weekly goals)
7. [NRI 5+1 Year Plan](07-nri-5plus1-year-plan.md) — full-year (Sem 1 + Sem 2) re-sequencing for job-outcome priority
8. [NRI Production Sequence](08-nri-production-sequence.md) — slot-by-slot session sequence for Python and Web App Dev 1
9. [NRI Day-by-Day](09-nri-day-by-day.md) — the daily runbook placing sequence slots onto specific days (weeks 1–3)

## Note on the source

The artifact's in-page tab navigation only wires up 7 of the 9 tabs (`curriculum, contents, exec, anatomy, student, nri, nri51`) — `nriseq` (Production Sequence) and `nriday` (Day-by-Day) exist as full sections in the page but have no clickable nav button, so they're only reachable by editing the URL hash (`#nriseq` / `#nriday`). Content-wise all 9 tabs are complete; this is a minor wiring gap in the original artifact's `<script>`, not a missing-data issue.
