## Where the AI FullStack track completes

**Why these three are lite:** the year's first allocation priority after BOS compliance is **DSA in full** — its complete sequence, problem-set surfaces and exam-prep own the PM lane and the Advance Track because it is the flagship university exam. FastAPI, Coding Agents and Capstone take the capacity that remains (they are also absent from NRI's approved year-1 catalogue, so they run as **compressed, NIAT-owned layers** — S7 thread, SA windows and buffer pools are NIAT instruments; no BOS change needed) and complete in Year 2. Coverage: **13/13 elite courses present** — 10 as full NRI equivalents, 3 as the layers below (~26 of the 54 deferred sessions recovered in-year, ~28 to Year 2).

| Elite course | Year-1 form at NRI | Slots | Funded from | Year-2 completion |
|---|---|---|---|---|
| Backend with FastAPI (14) | **FastAPI Essentials — 8 sessions**, wks 5–7 AM: first API · routing/Pydantic · SQLModel CRUD ×2 · JWT-lite · env + deploy · React integration · fullstack build | ~18 | Phase-A hardening pool (~90 slots) | +6 (SSE/streaming · files · hardening) + Node depth |
| App Dev using Coding Agents (22) | **Agents Starter — 6 sessions**, S7 wks 10–16, practiced on the capstone: agentic loop · AGENTS.md/config · spec-first · feature dev · review & verify · workflow portfolio | ~7 | S7 slots freed by the NxtMock retarget | +16 (codebase labs · cloud/CI-CD agents · ops) |
| AI FullStack Capstone (18) | **Capstone-lite** — the student's **own scoped product** (React + FastAPI + LLM feature), not an LLM-Apps assignment: spec wk 12 · **capstone studio ×3 AM slots/wk** wks 13–14 · evals + hardening wk 16 · **SA-5 = Demo Day** | ~22 | Phase-B AM slack (~32 slots) | Full capstone ladder; comm sessions via English Adv Saturdays |

**Capstone ≠ LLM Apps:** LLM Apps' in-course builds (DocuChat, interview assistant…) are course-scoped teaching artifacts graded inside that course; the capstone is the student's own scoped product with its own spec, rubric and Demo Day. The AM block splits explicitly in wks 12–14: LLM Apps ~9 · capstone studio 3 · practice ~3 of 15 slots/wk. **NxtMock retarget:** mocks no longer own thread slots — every Skill Assessment gains a **mock-defend** ("walk me through your build") and Demo Day carries the final interview rehearsals; the 8-mock completion metric is unchanged. **Year-1 exit:** a shipped React + FastAPI + SQL + LLM-feature application, built agent-natively. **Integrity:** no BOS sequence, Saturday economics or DSA watch-lane slot is touched. **Dependency:** this layout rides the Advance Track — in the fallback variant the layers compress (FastAPI ~10 slots · capstone-lite = SA-5 + 1 wk) and the fullstack outcome degrades. **Action:** file full FastAPI · Coding Agents · Capstone for the Year-2 BOS/VAC cycle now.

## Gap & Re-entry — the decision table (R18–R21)

| Gap | Day-1-back delivery | Then | Topic-start rule |
|---|---|---|---|
| Weekend + BOS day (2.5 d, weekly) | Current mode + **warm-start Revision rider** (R4) | unchanged | Module boundaries Tue–Thu only (R5) |
| Festival (~1 wk: Dasara, Sankranthi) | **MC reactivation** — no new content slot 1 | SME mode from day 2–3 | Boundary-shift first; forced starts → Studio-A/B, logged (R19) |
| Mid exams (1.5–2 wk) | Light MC + exam debrief | New-course MC (boundaries aligned to exams) | Complete before mids; never straddle (R20) |
| Sem break (3–5 wk) | 2–3 day **reactivation window** + diagnostic gate | normal | Dependents start only after bridge passes (R21) |

**SME-mode precedence:** prod-sequence order immutable → SME mode honored wherever the calendar allows → gaps handled by boundary-shifting, not mode-changing → forced substitutions choose the higher-immersion mode for the colder subject → every substitution deviation-logged with rationale against the priority order.
